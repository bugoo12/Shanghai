Google Sheets(`대시보드 일정`·`대시보드 숙소` 탭)와 양방향으로 동기화되는 가족 여행 대시보드입니다.
원본 `시트1` 탭은 수정하지 않습니다. 연결·배포 방법은 [SETUP.md](SETUP.md)를 참고하세요.

- 일정 추가·수정·삭제·완료 체크 → 시트 자동 저장
- 시트에서 직접 수정·행 추가 → 약 15초 후 대시보드 자동 반영(빈 ID는 고유 ID 자동 생성)
- 숙소명·중국어 숙소명·중국어 주소·메모 양방향 동기화
- 동시 수정 충돌 방지, 오프라인 보관 후 자동 재시도, JSON 백업·인쇄·모바일 지원
- 중국어 장소·숙소 주소 클릭 시 고덕지도 검색 연결
